# Artwork

Put the images this branding uses here (they are mounted into the app's static folder):

| File | Used as |
|---|---|
| `hero.png` | the full-page background artwork (mounted as `/alexander-hero-2.png`) |
| `favicon.png` | the browser tab icon (512x512, square, transparent) |
| `favicon-32.png` | the small tab icon (32x32) |
| `apple-touch-icon.png` | the home-screen icon (180x180) |
| `card-1.png` … `card-4.png` | the Explore-agents card images (portrait, about 550x720) |

Binary artwork is not committed to this repository by default (see `.gitignore`); drop your
own files in this folder before deploying, or commit them if you prefer.
